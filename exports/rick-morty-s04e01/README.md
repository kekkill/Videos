# Рик и Морти — 10 роликов для TikTok

Четыре самостоятельных момента и две истории по три части. 1080×1920,
23.976 fps, отражённый видеоряд, небольшое кадрирование, оригинальный звук,
заголовки сверху и мягкая золотистая подсветка русских субтитров снизу.
Рекламы и Minecraft-таблички нет. Скорость речи сохранена.

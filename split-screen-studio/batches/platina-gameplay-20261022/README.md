# Шесть роликов + шары + Platina VPN

Заказ от 22 октября 2026, папка Drive 1Y2EvOmY6_0nnuixyc8MPKge73bnc834-. Шесть готовых вертикальных роликов с их исходными субтитрами размещены сверху; снизу — активные фрагменты предоставленных трёх файлов с шарами, без звука. Два игровых файла содержат одинаковый видеопоток, поэтому различаются старты и комбинации. Пустые окончания записей исключены.

Каждая половина 1080×960, итог 1080×1920, 60 fps. Верхняя область исходника 1080×1440 равномерно вписана в 720×960 с размытыми краями, сохраняя лица и субтитры. Кольца игры масштабируются одинаково по обеим осям. Основная речь, музыка, скорость и ориентация сохранены; новые слова, титры и отражение не добавляются.

Баннер из document_5391052145464222374.mp4: удалён синий хромакей, зелёные надписи и голубые значки сохранены. Ускорение ровно 1,3×; atempo сохраняет высоту голоса. Подготовлено 250 прозрачных кадров 60 fps, 944×444, положение(68,738),центр(540,960). Длина вставки 4,1667с.

Вставка у границы реплик около середины. Всё изображение замирает на 3,75 с, основной звук отключён. Рекламная речь заканчивается примерно к 3,65 с. После паузы исходный монтаж продолжается с того же кадра с уровнем −18 dB; после конца баннера громкость возвращается за 120 мс. Все исходные кадры и слова сохраняются. Длина результата: исходник+3,75с.

## Восстановление и Studio

Требуются Node, FFmpeg/ffprobe, Python с numpy/Pillow и Chromium. Использовать существующие зависимости, если они установлены; не создавать Git worktree.

```sh
npm ci --no-audit --no-fund
python -m pip install -r requirements.txt
python scripts/restore-inputs.py
npm run lint
npm run dev -- --port=3008 --no-open --browser-executable=/usr/bin/chromium
```

restore-inputs.py скачивает пользовательские исходники по Drive ID, проверяет SHA256 и не перезаписывает изменённые файлы. Прозрачные кадры и ускоренный звук баннера сохранены в assets/, повторная загрузка original document MP4 для обычной работы не нужна. Для подготовки другого баннера необходимо отдельно удалить его хромакей, измерить конец речи и пересчитать тайминги — не переносить параметры этой вставки автоматически.

Композиции Platina-01…Platina-06. Внутренняя проверка Studio: `node scripts/check-studio.cjs`. Реальные кадры: `node scripts/preview.cjs`. Пользователю отдавать MP4 через GitHub, не адрес Studio.

## Экспорт и проверки

```sh
python scripts/export-base.py
python scripts/check-base.py
python scripts/export.py
python scripts/check.py
node scripts/check-playback.cjs
```

Первая стадия составляет изображение 50/50, копируя исходные AAC-пакеты без изменений. Вторая добавляет паузу и рекламу, сохраняя каждый исходный кадр. H.264 CRF18 veryfast, 60 fps, BT.709, AAC 320 кбит/с 48 кГц. Во время рекламы изображение смешивается в RGB. Аудио на второй стадии перекодируется для смешивания; при пиках выше 0 dBFS применяется ограничитель с компенсацией задержки, что записывается в audio.json.

Проверяются все кадры основного окна и субтитров, все временные метки, точные звуковые пакеты первой стадии, игровые фрагменты, все 250 кадров баннера, прозрачность/кайма и уровни звука во время паузы и после неё. Последняя проверка запускает и перематывает каждый MP4 в Chromium. Отчёты — out/base-validation.json,out/validation.json,out/playback-check.json.

Исходники исключены из Git. Предыдущие партии не изменяются. При смене настройки экспорта проверять кэш signature и увеличивать version при изменении графа.

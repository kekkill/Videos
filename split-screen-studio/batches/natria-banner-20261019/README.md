# NATRIA VPN — шесть роликов с паузой

В каждый готовый ролик с шариками добавлен исходный анимированный баннер NATRIA. Вставки выбраны у границ реплик, в пределах четырёх секунд от середины. Прежние кадрирование, субтитры, ориентация и скорость сохранены.

Баннер расположен точно по центру: 944×400, x=68, y=760 в кадре 1080×1920. Никаких дополнительных плашек. Его зелёный фон удалён, тонкие края очищены до масштабирования с учётом прозрачности. Исходный дизайн и звук сохранены.

В начале вставки весь составной кадр замирает на 5 секунд, основной звук отключается. Озвучка рекламы заканчивается до возобновления. Затем исходный ролик продолжается с того же кадра: ещё 2,2 секунды с уровнем −18 dB, после исчезновения баннера возвращается обычный уровень за 120 мс. Ни слова и ни кадра исходного монтажа не удалены. Итоговая длительность увеличена на 5 секунд.

## Восстановить проект

Требуются Node, FFmpeg с libx264, Python и Chromium. Запускать из каталога этого проекта:

```sh
npm ci --no-audit --no-fund
python -m pip install -r requirements.txt
python scripts/restore-inputs.py
npm run lint
npm run dev -- --port=3007 --browser-executable=/usr/bin/chromium
```

Используйте существующие зависимости, если они уже установлены. Не создавать новый Git worktree. Исходные шесть MP4 восстанавливаются по неизменяемым публичным ссылкам и SHA256 из data/base-inputs.json. assets/ содержит проверенные прозрачные кадры и исходный звук баннера; исходный зелёный MP4 для обычной работы не нужен. Восстановление не перезаписывает изменённые медиа.

В Studio доступны Natria-01…Natria-06. Для внутренней проверки запущенного Studio: `node scripts/check-studio.cjs`. Реальные кадры Remotion: `node scripts/preview.cjs`. Пользователю выдавать готовые MP4 через GitHub, а не адрес Studio.

## Экспорт и проверка

```sh
python scripts/export.py
python scripts/check.py
node scripts/check-playback.cjs
```

Экспорт: H.264 CRF18, 60 fps, 1080×1920, BT.709, AAC 320 кбит/с, 48 кГц. Изображение во время вставки компонуется в RGB; вне неё исходный YUV не проходит промежуточного преобразования цвета. Аудио перекодируется для смешивания и точной паузы. В шестом исходнике есть краткие пики выше 0 dBFS; только для него применяется ограничитель −0,18 dBFS с компенсацией задержки.

Проверка сравнивает каждый исходный кадр с правильным кадром результата, все 432 кадра баннера с независимым наложением, уровень основного звука во время рекламы и после неё, точные временные метки. Отдельно проверяется запуск и перемотка всех MP4 в Chromium. Результаты — в out/.

`python scripts/export.py --only 01-african-court --sample` создаёт 9-секундный пробник вставки. Полный экспорт кэшируется по настройкам и хешам баннера/аудиоскрипта. При изменении композиции нужно увеличить version в export.py.

Необязательная повторная подготовка ключа из оригинального вложения: `python scripts/prepare-banner.py --source /path/NATRIA_VPN.mp4`. Это пересоздаёт производные assets/ и их контрольные суммы; затем повторить restore-inputs.py. Для текущих готовых файлов она не нужна.

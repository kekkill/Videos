Все шесть исходных роликов — вертикальные, с вшитыми субтитрами. Новые титры,
субтитры, баннеры и отражение не добавлены. Голос, музыка, эффекты, скорость,
порядок сцен и тайминги сохранены. Оригинальные AAC-пакеты копируются в MP4

Холст 1080×1920, 60 fps, две области ровно 1080×960. Для читаемости лиц и
имеющегося текста основная область исходника x0/y0/1080×1440 вписана в
720×960 по центру верхней половины, боковые края заполнены размытием.
Нижние 480 пикселей исходного кадра в итоговом верхнем окне не показываются.
Входные файлы сохраняются полностью отдельно; данный монтаж не меняет их.
Кольца игры уменьшены равномерно до 900×900, счётчик перенесён в верхний
левый угол нижней половины. Для каждого ролика выбраны собственные старты
и сочетания двух или трёх игр. Пустые окончания источников не используются.

Изображение повторно кодируется H.264 CRF18: первые два ролика — preset fast,
остальные — veryfast для ускорения сборки при той же настройке качества. Сохранение разрешения
не означает отсутствие потерь. Число кадров и временные метки совпадают с
исходными роликами. У исходников звук заканчивается на 40–83 мс позже видео;
эта исходная разница сохраняется, дополнительного обрыва речи нет.

## Запуск

Нужны Node/npm, FFmpeg/ffprobe, Python3, `/usr/bin/chromium`.

```bash
npm ci --no-audit --no-fund
python -m pip install -r scripts/requirements.txt
python scripts/restore-inputs.py
npm run lint
npm run dev -- --no-open --port=3006
```

В другом процессе: `node scripts/check-studio.cjs`. Он открывает реальную
композицию Folder-01 в Chromium и ждёт загруженные видеослои.
Композиции Folder-01…Folder-06 имеют отдельные регистрации и игровые
отрезки. `src/Root.tsx` содержит их таймлайн, `src/Layout.tsx` — компоновку.
Фон в Studio приблизительный; финальные размытие и сборку делает FFmpeg.

В текущей среде проект расположен в
`/workspace/folder-gameplay-20261019/studio`, Studio3006. Не запускайте
повторный экспорт завершённой партии без нового запроса. После перезапуска
среды сервер Studio нужно запустить заново; файлы и зависимости сохранены.

## Восстановление и экспорт

`data/input-manifest.json` хранит Drive ID, имена, размеры и SHA-256 всех
двенадцати входных файлов. `restore-inputs.py` проверяет существующие файлы,
загружает только отсутствующие с проверкой TLS и контрольных сумм. Отличные
пользовательские файлы не заменяет. Исходные видео и игры не публикуются в Git.

Границы и подбор игр для FFmpeg находятся в `data/clips.json`.
После изменения таймлайна меняйте также соответствующие узлы в Root.tsx,
чтобы Studio показывала те же отрезки. Сохраните прежние результаты под
другим именем перед намеренной заменой экспорта.

```bash
python scripts/export.py
python scripts/check.py
node scripts/check-playback.cjs
```

`--only 01-african-court` ограничивает экспорт одним роликом, `--sample`
создаёт первые три секунды. Полный экспорт возобновляется с завершённых
файлов, если параметры совпадают. Текущая сборка записывает прогресс в
`out/batch.log`, проверки — в `out/qa.log`.

Проверяются все кадры основного окна, включая исходные субтитры, все
временные метки, все звуковые пакеты, размеры и отсутствие лишних дорожек.
Каждый игровой отрезок сравнивается с записью в начале, середине и конце.
Полный MP4 декодируется; Chromium проверяет начало и конец с перемоткой.
Итоговые прямые ссылки после публикации проверяются полным скачиванием
без авторизации и сравнением SHA-256. Отчёты лежат рядом с MP4.

# Вертикальный монтаж 50/50 — 17 октября 2026

Один ролик 1080×1920, 60 fps, около 64,8 секунды.
Верхние 1080×960 пикселей занимает предоставленный готовый монтаж.
Нижние 1080×960 пикселей — две игры подряд, без их звука.

## Согласованное размещение

- Основной ролик: https://drive.google.com/file/d/1WKwyDZJxY5b-eRqd4X7wuKTg1Us0lz3R/view
- Сверху сохранены лица и уже вшитые субтитры. Нижняя размытая подложка
  исходника исключена. Область 1080×1280 уменьшена до 810×960 без изменения
  пропорций; боковые края заполнены размытым изображением того же кадра.
- Снизу сначала идёт bouncing-ball-ring-escape-9x16-20s.mp4 (0–20 с),
  затем bouncing-ball-custom-9x16-40s.mp4 (20–60 с). До конца основного
  ролика повторяется начало второй игры. Скорость игр не меняется.
- Игровое поле масштабируется одинаково по обеим осям. Кольца видны целиком.
  Счётчик оставшихся колец сохранён отдельно под игровым полем.
- В итоговый MP4 попадают только исходные AAC-пакеты основного ролика.
  Аудио обеих игр не включено. Монтаж речи, музыка, эффекты и тайминг сохранены.
- Дополнительные титры, баннеры и отражение не применяются.
- Изображение перекодировано в H.264 CRF 18; это сжатие с потерями.
  Исходные файлы не изменяются.

## Воспроизведение сборки

Требуются Python 3 и FFmpeg с libx264. Отдельных Python-пакетов для рендера нет.
Сохраните основной ролик как source.mp4 рядом со скриптом или передайте путь.
Игровые записи пользователь предоставляет отдельно; в репозитории их нет.

```bash
python render_split_screen.py --source /path/source.mp4 --game1 /path/bouncing-ball-ring-escape-9x16-20s.mp4 --game2 /path/bouncing-ball-custom-9x16-40s.mp4
```

Для короткого образца добавьте `--preview`; он содержит первые 8 секунд.
Скрипт рассчитан на конкретные предоставленные исходники 1080×1920.
Для другой геометрии или положения субтитров требуется пересмотреть кадрирование.

## Проверка

validate_split_screen.py проверяет размер, число кадров, длительность,
полное декодирование, совпадение всех звуковых пакетов и их временных меток,
а также воспроизведение и перемотку в Chromium. Для браузерной части нужны
Python Playwright и Chromium по пути /usr/bin/chromium.

```bash
python validate_split_screen.py --source /path/source.mp4 --output /path/video-game-split-50-50.mp4
```

Файлы validation.json и composition-manifest.json фиксируют проверки и
параметры текущей сборки. Полные исходники и рабочие промежуточные MP4
не публикуются вместе со скриптами.

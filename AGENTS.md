# Работа с видео

Этот репозиторий принадлежит пользователю kekkill. Перед работой прочитай
VIDEO_WORKFLOW.md и NEXT_CHAT.md. Последняя прямая инструкция пользователя
имеет приоритет над сохранёнными настройками и предыдущими версиями роликов.

- Общайся по-русски. Пользователю нужны открывающиеся MP4, а не только исходники
  проекта, планы или ссылки на localhost.
- Сохраняй предыдущие экспорты и пользовательские изменения. Проверяй git status
  перед изменениями; не добавляй в коммит весь рабочий каталог автоматически.
- Для новых нарезок сериалов и фильмов: 9:16, исходный звук, горизонтальное
  отражение видеоряда один раз, обычное направление новых титров и субтитров.
- Отбирай законченные интересные моменты и связные истории из нескольких частей.
  Длительность выбирай по сцене. Не обрывай слова, развязку отдельного момента
  или важный контекст ради фиксированного числа секунд.
- Сверху размещай цепляющее название по реальному содержанию сцены. Для серии
  частей указывай фактическое «1/3», «2/3», «3/3» и сохраняй их порядок.
- Снизу — русские субтитры по фактической речи: светлый текст, тёмная обводка,
  мягкая золотистая подсветка текущего слова. Для фильмов/сериалов Minecraft-
  табличку не использовать. Баннеры не добавлять без отдельного запроса.
- Кадрирование выбирай по действию, сохраняя лица, предметы и смысл сцены.
  Не срезай персонажей только ради заполнения вертикального кадра.
- Голос, музыку и звуковые эффекты сохраняй. Не удаляй слова и не ускоряй звук
  без запроса. При нарезке допустимо перекодировать звук для точных границ:
  сохраняй его слышимое содержание и синхронизацию, не обещай побайтовую копию.
- Субтитры распознавай для каждого исходника отдельно; временные метки храни
  относительно исходника, затем учитывай начало выбранного отрывка.
- Проверяй читаемость титров, размещение с учётом TikTok, переполнение строк,
  точность имён и реплик, отсутствие выглядывающего исходного текста,
  декодирование MP4, звук и начало/конец каждого ролика.
- Доставляй через GitHub kekkill/Videos: exports/ и прямые ссылки на скачивание.
  Используй существующую авторизацию, не запрашивай токен без проверки доступа.
  Пользователь уже разрешил эту доставку; не спрашивай повторно для каждого файла.
- Не утверждай, что новый чат создан или подключён, если такого инструмента нет.
  Новый чат начинает работу с сохранённых документов и фактического состояния файлов.

Прежний Minecraft-процесс описан в VIDEO_WORKFLOW.md отдельно. Не применяй
его табличку и правила сохранения полного монтажа к нарезкам фильмов автоматически.

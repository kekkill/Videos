# Рик и Морти — серия про Рика Прайма

Новая подборка из исходника пользователя от 17 октября 2026 года:
**10 MP4 — четыре отдельных момента и две истории по три части**.
Это самостоятельный проект этой подборки; прежние десять роликов из С4/С1
и их исходники сохранены в основном story-studio.

Видеоряд отражён один раз, заголовки и новые субтитры читаются в обычном
направлении. Формат 1080×1920, исходные 30 fps. Сохранены оригинальные голоса,
музыка, эффекты и скорость речи. В выбранных сценах не обрезаны отдельные слова.
Убраны вступительная пауза записи, длительный неподвижный хвост и некоторые
паузы/переходы между законченными репликами. Длина выбрана по содержанию.
Minecraft-таблички и рекламных слоёв нет.

Оформление повторяет предыдущую подборку: широкий план сцены с небольшим
увеличением, размытый фон, заголовок сверху, номер части у историй, светлые
субтитры с обводкой и мягкой золотистой подсветкой #e6c777 внизу.
Заголовки и фразы проверяются на переполнение. Размещение оставляет отступы
под интерфейс TikTok; конкретный интерфейс зависит от устройства.

Субтитры распознаны отдельно для нового исходника. Проверенные слова и таймкоды
относительно оригинала находятся в data/reviewed-source-words.json. Модель
распознавания пропускала некоторые тихие реплики на фоне эффектов: для них
сохранено отдельное распознавание без фильтра голосовой активности. В
reviewed-transcript.json каждого ролика сохранены локальные и исходные таймкоды;
src/Clips.tsx содержит редактируемые JSX-массивы каждого из десяти роликов.

## Качество и экспорт

Видеоряд перекодируется при добавлении титров: промежуточные сцены H.264 CRF 15,
готовые MP4 — H.264 CRF 18. Это сжатие с потерями с приоритетом визуального
качества. Размер файла и разрешение сами по себе не гарантируют отсутствие
потери данных. Исходная серия не заменяется экспортами.

Для точных границ монтажей исходный звук кодируется AAC 256 kbit/s, 48 kHz.
В готовый вертикальный MP4 звук переносится из подготовленного монтажа без
повторного кодирования. Проверяется совпадение всех его пакетов и таймингов;
побайтовая копия аудио из полной записи не заявляется.

## Восстановление и запуск

Нужны Node.js/npm, системные FFmpeg и Chromium (/usr/bin/chromium), Python venv
с faster-whisper и NumPy. Зависимости Remotion 4.0.534 и React 19.2.3 закреплены.
Рабочая папка в текущей среде: /workspace/story-clips-20261017/studio.

```bash
export npm_config_cache=/workspace/.cache/npm
npm ci --no-audit --no-fund
/workspace/.venvs/snail-audio/bin/pip install -r scripts/requirements.txt
python scripts/restore-media.py
python scripts/review-source-captions.py
python scripts/prepare-captions.py --transcript-suffix=-reviewed
npm run lint
npm run dev -- --no-open --port=3003
```

Повторное распознавание не нужно: проверенные данные уже сохранены.
Восстановление исходника проверяет SHA-256; отличающийся пользовательский файл
не перезаписывается. Промежуточные медиа и out игнорируются Git.

Из второго процесса:

```bash
node scripts/check-layout.cjs
/workspace/.venvs/snail-audio/bin/python scripts/run-batch.py
```

Процесс повторно использует уже готовые слои с совпадающими данными и стилем,
пишет out/batch-status.json и отдельные логи. Проверяет все кадры, субтитры,
геометрию, таймкоды, звуковые пакеты и воспроизведение начала/конца десяти MP4.
Не создаёт новый Git worktree и не меняет предыдущую подборку.

# Истории с физры + игра: десять роликов 50/50

Заказ 18 октября 2026: верхняя половина — десять уже согласованных нарезок,
нижняя — разные фрагменты шести записей игры пользователя. Баннеров нет.
Готовые файлы: `exports/phys-ed-gameplay-20261018/` в корне репозитория.

Холст 1080×1920, обе области ровно 1080×960. Сцена, заголовок, номер части
и пословные субтитры заново размещены в верхней половине. Мягкий золотой
цвет #e6c777 сохранён. Игровое поле равномерно уменьшено до 900×900:
кольца остаются круглыми и помещаются целиком. Счётчик перенесён в левый
верхний угол игрового поля, чтобы не занимать область нижнего описания TikTok.
Фактический интерфейс TikTok зависит от устройства.

Игры идут с исходной скоростью, звук игры исключён. Основной звук взят из
подготовленных монтажей без повторного кодирования. Основной видеоряд уже
отражён один раз, повторного отражения здесь нет. Экспорт — H.264 CRF18,
60 fps: исходные 24 кадра/с сцены повторяются, игровая запись сохраняет
60 кадров/с. Для десятого ролика сетка 60 fps добавляет 8,33 мс в конце
видеодорожки; звук и временная шкала речи не меняются. Изображение сжимается
повторно, разрешение само по себе не означает отсутствие потерь.

## Открытие и восстановление

Требуются Node/npm, FFmpeg/ffprobe, Python3, `/usr/bin/chromium`.

```bash
npm ci --no-audit --no-fund
python -m pip install -r scripts/requirements.txt
python scripts/restore-inputs.py
npm run lint
npm run dev -- --no-open --port=3005
```

В другом процессе: `node scripts/check-layout.cjs`. Эта проверка открывает
настоящую композицию Split-01, проверяет шрифт и все десять заголовков,
250 страниц субтитров. `node scripts/preview-split.cjs` сохраняет два кадра
Remotion. Размытие и фон в Studio приблизительные; финальный видеомонтаж
делает FFmpeg. Геометрия и оформление текста одинаковые.

В текущей облачной среде проект расположен в
`/workspace/phys-ed-gameplay-20261018/studio`, зависимости уже установлены,
исходники проверены. Сервер Studio должен запускаться заново после перезапуска
среды. Не запускайте повторный экспорт завершённой партии без нового запроса.

Исходные записи не включены в Git. `data/input-manifest.json` хранит ссылки
Drive и контрольные суммы. Скрипт восстановления проверяет уже имеющиеся
файлы, загружает только отсутствующие, проверяет TLS и SHA-256. Подготовленные
монтажи создаются из исходного эпизода с точными границами сцен. При отличии
файла или результата кодировщика скрипт сохраняет его для проверки.

## Изменение и экспорт

Слова и тайминги: `data/*-captions.json`. Заголовки, части и игровые отрезки:
`data/clips.json`. `src/Clips.tsx` читает Caption JSON напрямую; подписи
заголовков заданы там же. `src/Split.tsx` — интерактивная композиция 50/50,
`src/Common.tsx` — прежний шрифт и оформление.

После изменения оформления, заголовков или субтитров сохраните прежний `out/`
под другим именем, чтобы получить свежие слои и не потерять прошлые результаты.
Для изменения игровых отрезков без изменения текста достаточно экспорта.

```bash
node scripts/render-layers.cjs
python scripts/export-split.py
node scripts/check-layout.cjs
python scripts/check-split.py
node scripts/check-playback.cjs
```

PNG-слои рисует Remotion на границах слов с исходной частотой 24 fps.
FFmpeg собирает окончательные 60 fps, а затем копирует только звуковую дорожку
основной сцены. Проверка сравнивает каждый кадр субтитров, все звуковые
пакеты и временные метки, выбранные кадры основного видео и каждого игрового
отрезка, равномерность масштаба, полное декодирование и воспроизведение
начала/конца с настоящей перемоткой. Отчёты находятся в `out/` и каталоге
готовых файлов. Зависимости, исходники и временные PNG не публикуются.

# Videos

Готовые видеоролики доступны для скачивания из этого репозитория.

## Улитка — исправленная версия 2

- [1. Скачать ролик с табличкой и субтитрами, без русской озвучки](https://raw.githubusercontent.com/kekkill/Videos/main/exports/snail-v2-captions-only.mp4)
- [2. Скачать ролик с исправленной русской озвучкой](https://raw.githubusercontent.com/kekkill/Videos/main/exports/snail-v2-smooth-voice.mp4)

Оба файла — 1080×1920, 60 fps, около 24 МБ каждый. Видеоряд, оформление
таблички и субтитры одинаковы. В первом файле исходная музыка и игровые звуки
сохранены без перекодирования и изменения громкости. Во втором озвучка собрана
целыми предложениями: все слова сохранены, внутри речи срезов нет.

[Скачать архив с плеером](https://github.com/kekkill/Videos/archive/refs/heads/main.zip).
Распакуйте его целиком и откройте `exports/player.html` в браузере.

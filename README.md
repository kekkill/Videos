# Videos

Готовые видеоролики доступны для скачивания из этого репозитория.

## Улитка — субтитры для готового монтажа

[Скачать актуальный ролик](https://raw.githubusercontent.com/kekkill/Videos/main/exports/snail-user-edit-captions.mp4)

1080×1920, 60 fps, 27,84 секунды, около 27 МБ. На готовый монтаж пользователя
добавлены Minecraft-табличка и русские субтитры короткими смысловыми фразами
с жёлтой подсветкой произносимого слова. Голос, музыка и игровые звуки
скопированы из нового исходника без изменений и перекодирования.
Сохранены все 1670 видеокадров и их тайминг.

[Скачать архив с плеером](https://github.com/kekkill/Videos/archive/refs/heads/main.zip).
Распакуйте его целиком и откройте `exports/player.html` в браузере.
По умолчанию плеер открывает актуальный ролик; предыдущие варианты сохранены.

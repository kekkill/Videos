Обновлено 14 октября 2026 года. Репозиторий: kekkill/Videos, ветка main.
Публикация: TikTok. Итоговые файлы нужно отдавать через GitHub, потому что
ссылки на файлы облачной рабочей среды у пользователя часто не открывались.
Google Drive используется для получения исходников по доступной ссылке;
загрузка готовых файлов на Drive ранее была недоступна через инструменты.

## Новый формат: фильмы и сериалы

Минимум 10 роликов из предоставленного исходника. Нужна смесь самостоятельных
интересных моментов и связных историй, разбитых на части. Длительность зависит
от сцены: пользователь не задаёт единую длину для обоих форматов.

Видеоряд отразить по горизонтали. Кадрирование и выбор крупного плана допустимы,
если сохраняют важное действие. При нескольких действующих персонажах лучше
оставить более широкий план, чем потерять участника разговора.

Сверху — короткий цепляющий заголовок, который соответствует сцене. Номер
части указывать только для реальной серии частей, например «1/3». Снизу —
русские пословные субтитры без Minecraft-таблички. Пользователь подтвердил:
светлые буквы, тёмная обводка и мягкая золотистая подсветка, без яркого жёлтого.
Принятый оттенок из последнего ролика: #e6c777. Новый шрифт/размер допустимы
для читаемости. Рекламы и дополнительной озвучки в этом заказе нет.

Исходная речь, музыка и эффекты остаются синхронными. Внутри реплик не вырезать
отдельные слова. Для монтажа использовать точные границы сцен; выводимые
субтитры сверять с реальным звуком, не заменять речь произвольным пересказом.

## Что проверять перед доставкой

Вертикальный формат, чёткий читаемый текст, направление новых надписей,
правильные части и заголовки, начало/конец без обрезанных слов, синхронизацию
голоса и подсветки. Заголовки и субтитры размещать с отступом от верхних
элементов TikTok, правых кнопок, нижнего описания и навигации. Конкретный
интерфейс зависит от устройства: не обещать универсальную безопасную зону.

Проверять весь файл на ошибки декодирования, воспроизведение в браузере,
длительность и разрешение. Прямую ссылку GitHub скачивать без авторизации
и сравнивать размер и SHA-256 с локальным экспортом. Для большого заказа
давать список отдельных MP4 и общий ZIP, если размер позволяет доставку.

## Прежний формат: Minecraft

Для готового монтажа обычно добавляются только табличка и русские пословные
субтитры; голос уже подогнан пользователем. Не удалять «этот», «тут же»
и другие произнесённые слова: прежние сокращения звучали обрывочно.
Сохранять исходные звук, музыку, эффекты, тайминг и геометрию, если пользователь
не просил изменить их. Последний заказ не требовал отражения или обрезки.

Последняя одобренная табличка: 850×200 вместо 930×240, x115/y1182 для
1080×1920, непрозрачная область x128/y1204/824×140. Шрифт Russo One,
светлые слова #fff5df, подсветка #e6c777, тёмная обводка. Она закрывает
вшитые английские субтитры даже между фразами. Для другой позиции исходного
текста размеры маски нужно проверять заново. Эти координаты не применять
к фильмам и сериалам.

Последний Minecraft-файл: exports/friend-link-soft-captions.mp4, 35 секунд,
1080×1920, 60 fps, без баннеров и обрезки. Прежние файлы оставлены в exports/.

зависимостями, генераторами титров/субтитров, восстановлением медиа по Drive
и проверками экспорта. В текущей среде: /workspace/Videos/story-studio,

проверена локальная модель large-v3-turbo; сохранённые субтитры можно менять
без повторного распознавания. Не начинать повторный монтаж готовых десяти
файлов без новой просьбы; проверить NEXT_CHAT.md.

В текущей облачной среде прежний Remotion-проект находится в
/workspace/Videos/minecraft-studio. Установлены Node.js/npm, FFmpeg,
/usr/bin/chromium, Remotion 4.0.534 и React 19.2.3. Есть Python venv
/workspace/.venvs/snail-audio и локальная модель faster-whisper small
в /workspace/.cache/huggingface. GPU нет; распознавание выполняется на CPU.
